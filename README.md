## &#9873; MVC Architecture

MVC stands for Model-View-Controller. It is one of the software architectural pattern that separates an application into three interconnected logical components.

- Model:
  
  - This represents the data or resource for the application. It might handles data retrieval, storage, and manipulation by interacting with the database or file system. In Laravel, Eloquent ORM is commonly used within models.

- View:
  
  - This is responsible for presenting the data to the user. It is the user interface, where the visual elements are generated and rendered.

- Controller:
  
  - This acts as the intermediary region between the Model and View. It receives user input and requests. Then it will processes with application logics and interacts with the appropriate Model to handle data, and then passes those data to the View for display. Essentially, it controls the flow of the application.

## &#9873; Laravel Framework

Laravel is a one of the PHP web framework. It is designed for building robust and elegant web applications in PHP. It aims to simplify common web development tasks, such as routing, authentication, caching, securities and database interactions by providing a clean and expressive syntax.

Commonly known with followings:
- Built on PHP.
- Leveraging PHP Features by utilizes modern PHP features such as namespaces, interfaces, and closures to create and implement a powerful and efficient framework.
- Laravel uses composer dependency manager.
- Laravel uses Eloquent ORM for Models, Blade template engine for Views (Optional), Routings and Controllers for handling requests and artisan CLI to simplify the work process.
